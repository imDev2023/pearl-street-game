# T-011: Tavern (mercenary lending)

Status: backlog
Blocked by: T-010

## What to build

Idle creatures earn by being hired as battle reinforcements, ported from Crabada's Tavern.

Owners list creatures at a self-set CLAM price; hirers pay to use them as reinforcements only (never as core party members).
The tavern takes a 10% rake in CLAM to the treasury and prize pool.
Hired creatures return unharmed after battle and enter a cooldown.

## Acceptance criteria

- [ ] List, hire, reinforce, return, and cooldown flow works end to end
- [ ] Rake is exact and routed correctly
- [ ] Owners can delist any time the creature is not in battle
